\begin{center}
    \Large\bfseries Preface
\end{center}
\vspace{0.1cm}

The increasing demand for reliable, accessible, and personalized medical information motivates the development of intelligent medical assistant systems. Users often describe symptoms in incomplete or informal language, search for medical information from sources of uneven quality, and may need support across multiple interactions rather than a single isolated conversation.

Recent advances in large language models, retrieval-augmented generation, knowledge graphs, multimodal models, and agent orchestration provide an opportunity to build medical AI systems that are more grounded, modular, and context-aware. However, medical AI also introduces safety challenges, including hallucination, incomplete clinical context, uncertain visual interpretation, and the need for human feedback.

This report presents a Multi-Agent Medical Assistant that integrates text-based medical reasoning, medical image analysis, long-term memory, and human-in-the-loop validation. The work focuses on AI techniques and system-level reasoning rather than user interface or backend implementation details.

\begin{center}
    \Large\bfseries Summary of Content and Contributions
\end{center}
\vspace{0.1cm}

This report studies a multi-agent medical assistant designed around four main technical pillars:

\begin{itemize}
    \item \textbf{Text-based medical reasoning:} The system combines Multi-hop Question Answering, Retrieval-Augmented Generation, Knowledge Graph reasoning, and Web Search fallback to produce more grounded and cautious medical responses.

    \item \textbf{Vision-based medical reasoning:} The Vision Module supports general medical image interpretation, colonoscopy polyp segmentation, and Polyp Visual Question Answering. The Polyp VQA component uses a LoRA fine-tuned Vision-Language Model and compares original-image reasoning with segmentation-grounded reasoning.

    \item \textbf{Long-term memory for agent continuity:} Mem0 is integrated as a memory layer that stores clinically useful patient-reported facts across sessions, helping agents maintain continuity while avoiding unsupported diagnostic claims.

    \item \textbf{Human-in-the-loop validation:} The system includes a validation mechanism for collecting user feedback and supporting safer review of generated responses.
\end{itemize}

The main contribution of this work is an AI-centered architecture that combines specialized agents, structured and unstructured knowledge retrieval, visual grounding, long-term memory, and validation-oriented safety mechanisms for medical assistance.
