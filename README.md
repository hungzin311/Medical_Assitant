# Medical Assistant

![System Overview](system.png)

This project is a multi-agent medical assistant system that integrates advanced AI for medical image analysis, information retrieval, and conversational support.

## Features
- Medical image classification and diagnosis
- Retrieval-augmented generation (RAG) for medical questions
- Real-time web search for up-to-date medical information
- Multi-agent orchestration for robust and accurate responses

## Quick Start
1. Clone this repository
2. Install dependencies from `requirements.txt`
3. Run the application as described in the documentation
